# 3-Statement Financial Model with Scenario Analysis

## Overview
A comprehensive financial modeling tool built in Excel that integrates three financial statements (Income Statement, Balance Sheet, and Cash Flow Statement) with flexible scenario analysis capabilities. The model includes historical data analysis and five-year forecasting functionality.

## Features
- **Integrated 3-Statement Model**
  - Dynamic P&L projections
  - Automated balance sheet balancing
  - Cash flow statement with working capital analysis
  - Multiple business segment analysis (Supermarkets, Discounters, Grocery, Retail)

- **Scenario Analysis**
  - Flexible growth rate assumptions
  - Working capital optimization scenarios
  - Margin sensitivity analysis
  - Customizable driver inputs

- **Financial Metrics**
  - EBITDA margin analysis
  - Working capital efficiency ratios
  - Interest coverage calculations
  - Tax impact assessment

## Using the Model
1. **Input Section**
   - Navigate to the 'Workings' sheet
   - Update key assumptions in highlighted cells
   - Review growth rates and margin assumptions

2. **Scenario Analysis**
   - Use dropdown menus for scenario selection
   - Adjust drivers in the scenario manager
   - Review impact across all statements

3. **Output Review**
   - Check summary dashboard
   - Review key metrics and ratios
   - Verify statement balancing

## Key Assumptions
- Revenue growth based on historical trends
- Cost structure aligned with industry standards
- Working capital days calculated from historical data
- Tax rates based on current regulatory framework

## Model Validation
- Built-in error checks
- Balance sheet reconciliation
- Cash flow verification
- Scenario consistency checks
